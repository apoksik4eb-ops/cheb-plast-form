==================================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА "ПОЛИФОРМ" (Django)
==================================================

Для запуска проекта на локальном компьютере выполните следующие шаги.

1. КЛОНИРОВАНИЕ РЕПОЗИТОРИЯ
--------------------------------------------------
Скачайте проект и перейдите в папку:
git clone https://github.com/apoksik4eb-ops/cheb-plast-form
cd cheb-plast-form

2. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ
--------------------------------------------------
Создайте и активируйте виртуальное окружение:

Для Windows (PowerShell):
  python -m venv .venv
  .venv\Scripts\activate

Для macOS/Linux:
  python3 -m venv .venv
  source .venv/bin/activate

3. УСТАНОВКА ЗАВИСИМОСТЕЙ
--------------------------------------------------
Установите необходимые библиотеки из файла requirements.txt:
  pip install -r requirements.txt

4. СОЗДАНИЕ ФАЙЛА НАСТРОЕК .env
--------------------------------------------------
В корневой папке проекта (там, где лежит manage.py) 
создайте файл с названием .env и добавьте в него строки:

  SECRET_KEY=ваш_секретный_ключ
  DEBUG=True
  ALLOWED_HOSTS=localhost,127.0.0.1

Вместо "ваш_секретный_ключ" вставьте любую случайную строку. 
Если хотите сгенерировать надежный ключ, выполните команду:
  python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
и скопируйте результат.

5. ПРИМЕНЕНИЕ МИГРАЦИЙ
--------------------------------------------------
Создайте структуру базы данных:
  python manage.py migrate

6. СОЗДАНИЕ АДМИНИСТРАТОРА (СУПЕРПОЛЬЗОВАТЕЛЯ)
--------------------------------------------------
Создайте аккаунт для входа в панель управления:
  python manage.py createsuperuser
(придумайте логин, email и пароль)

7. ЗАПУСК СЕРВЕРА
--------------------------------------------------
Запустите локальный веб-сервер:
  python manage.py runserver

==================================================
ГОТОВО!

Клиентская часть сайта: http://127.0.0.1:8000/
Панель администратора:  http://127.0.0.1:8000/admin/
